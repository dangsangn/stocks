# Heo Đất đi chứng khoán

Giáo trình đầu tư chứng khoán cho người mới, kể bằng truyện tranh hoạt hình với hai nhân vật Heo Đất và Cú Già.

Mở `index.html` bằng trình duyệt để bắt đầu. Tiến độ bài tập và nhật ký đầu tư được lưu trên trình duyệt; hãy dùng nút sao lưu trong trang nhật ký để giữ dữ liệu.
